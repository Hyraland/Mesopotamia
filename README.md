# 河流与圣台 · Mesopotamia

在浏览器里步行游览一座南部美索不达米亚的河畔城镇：塔庙与圣区、院落住宅、码头集市、乌鲁克时期的遗迹，以及河对岸的冲积平原。可以在白天、黄昏、夜晚之间切换，配乐依据古巴比伦泥板记载的里拉琴调弦实时合成。

## 运行

这是纯静态页面（three.js 从 CDN 加载），任意静态服务器都可以：

```bash
python3 -m http.server 8000
```

然后打开 http://localhost:8000/ 。

## 操作

| 按键 | 作用 |
| --- | --- |
| 拖动 | 环顾四周 |
| W A S D / 方向键 | 行走 |
| Shift | 奔跑 |
| F | 飞行（空格 上升 · C 下降） |
| E | 在塔庙顶上：随鹰鸟瞰 |
| T | 换时段 |
| M | 音乐开关 |

右上角的 ··· 菜单里也有操作说明、时段切换、音乐开关与音量、致谢。

## 文件

- `index.html`：页面入口；`src/main.js`：渲染与主循环。
- `tuning.json`、`tuning_dusk.json`、`tuning_night.json`：白天、黄昏、夜晚的光影参数。
- `models/`：场景用到的模型。
